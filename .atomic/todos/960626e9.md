## ✅ AI 聊天面板交互优化

### 1. 停止生成
- 流式输出时底部显示 **警告色「停止生成」按钮** + 「AI 正在生成中...」提示
- 点击后 AbortController.abort() 中断 fetch
- 已生成内容保留为一条消息（加 *[已停止生成]* 标记）

### 2. 清除按钮设计
- ✕ 关闭 → 清空消息 + 移除 repo 上下文 + 关闭面板
- 🗑 清除 → 清空消息 + 移除 repo 上下文标签，回到欢迎态
- 标签 ✕ → 仅移除 repo 上下文，保留消息（可切换话题）
- 重新打开面板 = 全新对话

### 3. 欢迎态智能切换
- 有 repo 上下文 → 4 个代码分析快捷问题
- 无 repo 上下文 → 引导用户搜索仓库

### 4. 技术实现
- AbortController 传递给 fetch signal
- catch AbortError 静默处理
- clear-context 事件通知 layout 重置 globalChatRepo/globalChatRepoData
